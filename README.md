# E-la Integrated Administration Platform

ระบบบริหารงานสถานศึกษาแบบ Modular สำหรับวิทยาลัยเทคนิคดอนเมือง
แกนกลางคือข้อมูลบุคลากรและระบบสิทธิ์ RBAC + ABAC ตามสายบังคับบัญชา 5 ระดับ
โมดูลธุรกิจ (ลา ลงเวลา OT สารบรรณ แจ้งเตือน) และโมดูลในอนาคตเสียบเข้ากับแกนกลางผ่าน manifest
