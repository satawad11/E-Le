## ขั้นที่ 1 — เตรียมข้อมูลแม่แบบ

```
php artisan document:backfill-versions   # แม่แบบทั้ง 10 มีเวอร์ชันครบ
php artisan document:import-forms        # แนบไฟล์ราชการ 5 ฉบับเป็นฉบับร่าง
php artisan document:scaffold-fields     # วางชุดฟิลด์ตั้งต้น 23–26 ช่องต่อแบบฟอร์ม
```

แก้เพิ่มระหว่างซ้อม: `document:scaffold-fields` เดิมกรองแม่แบบด้วย `render_mode` ของ *แม่แบบ*
จึงหาแบบฟอร์มที่เพิ่งนำเข้าไม่เจอเลย (เพราะการนำเข้าไม่เปลี่ยน render_mode ของแม่แบบโดยตั้งใจ)
และคีย์ฟิลด์เฉพาะยังอ้างชุด `form_*` ของรุ่นเก่า — แก้ทั้งสองจุดแล้ว
ส่วน `document:import-forms` เพิ่มกติกา "ไม่สร้างฉบับร่างซ้อนหลังเผยแพร่แล้ว"

## ขั้นที่ 3 — เปิดใช้งานจริงและพิมพ์เอกสาร

เปิด `DOCUMENT_ENGINE_ENABLED=true` ใน `.env` ของเครื่องพัฒนา แล้วเปิดรายประเภทผ่าน
`POST /admin/document-engine/enabled-entities` = ประเภท 1–6 (ที่แบบฟอร์มเผยแพร่แล้ว)

| กรณีทดสอบ | ผล |
|---|---|
| ยื่นใบลาใหม่ (ลาป่วย) ผ่าน API ในฐานะพนักงาน | 201 · ใบลา pin เวอร์ชัน `leave_sick_personal v1 ACTIVE pdf_overlay` ทันที |
| พิมพ์ใบลานั้น | `Producer (FPDF 1.9)` = ออกด้วย Document Engine บนแบบฟอร์มราชการจริง |
| เนื้อหาบนเอกสาร | ตรวจ content stream แล้วพบ **เลขที่เอกสาร / ชื่อผู้ยื่น / เหตุผล** จริงบนแบบฟอร์ม |
| อนุมัติครบ 3 ขั้นแล้วพิมพ์ซ้ำสองครั้ง | ไฟล์ **md5 เท่ากันทุกไบต์** และมี `document_generated_files` FINALIZED revision 1 |
| ใบยกเลิกวันลา (`?form=cancel`) | 200 · `Producer (FPDF 1.9)` ใช้แบบฟอร์มใบยกเลิก |
| ประเภทที่ยังไม่เปิด (ลาไปศึกษาต่อ) | 200 · `Producer (dompdf 3.1.6)` = เส้นทางเดิม ทำงานคู่กันได้ |
| ดาวน์โหลด Word | `application/vnd.ms-word; charset=UTF-8` + ชื่อไฟล์ `.doc` ตรงกัน (LS-07) |

## ตรวจด้วยหน้าจอจริง

เข้าเว็บที่ `http://localhost:8001` ด้วยบัญชีผู้ดูแล:

- **หน้าออกแบบแบบฟอร์ม** — แสดงแบบฟอร์มราชการจริงเป็นพื้นหลัง มีกล่องฟิลด์ 26 ช่องวางทับ
  ไม้บรรทัดสองแกน ขนาดหน้า `595×842 pt` (ขนาดจริงจากไฟล์) แถบเครื่องมือพรีวิว 3 โหมด
  และแถบแจ้งว่าเวอร์ชันนี้เผยแพร่แล้วจึงแก้ไม่ได้
- **ศูนย์จัดการเอกสาร** — แถบสถานะ "ระบบจัดทำเอกสารอัตโนมัติ (Document Engine) เปิดใช้งานอยู่ ·
  ประเภทการลาที่เปิด: 1, 2, 3, 4, 5, 6" · แม่แบบ 10 · ตัวแปร 178 · เอกสารที่ออกแล้ว 1 (ฉบับสมบูรณ์ 1)
- **แผงเปิดใช้รายประเภท** — ติ๊ก 6 ประเภทที่พร้อม ส่วนที่เหลือบอกว่า "ยังไม่ได้ผูกแบบฟอร์ม" หรือ 0 ฟิลด์
- **หน้าประเภทการลา** — คอลัมน์ "แบบฟอร์มที่ใช้พิมพ์" แสดงชื่อแม่แบบ เวอร์ชัน จำนวนฟิลด์
  ป้าย "เปิดใช้แบบฟอร์ม PDF" และลิงก์ "เปิดหน้าออกแบบ"

## สิ่งที่ต้องทำต่างจากนี้เมื่อขึ้นเครื่องจริง

1. **ตำแหน่งฟิลด์ยังเป็นค่าประมาณ** — ชุดที่วางด้วย `document:scaffold-fields` มีไว้ให้เริ่มจากโครง
   ผู้ดูแลต้องลากให้ตรงช่องจริงแล้วพรีวิว/สอบเทียบก่อนเผยแพร่บนเครื่องจริง
2. **ตรวจตัวเลขก่อนรัน backfill** — ถ้าเครื่องจริงมีเอกสารที่ออกไปแล้วหรือใบลาที่ pin ไว้
   เงื่อนไขที่ทำให้การเติมเวอร์ชันปลอดภัยจะไม่เหมือนกับเครื่องพัฒนา (ดู DESIGNER-PHASE-5-STATUS)
3. **`DOCUMENT_ENGINE_ENABLED` บนเครื่องจริงเป็นการตัดสินใจของเจ้าของระบบ** และควรเปิดทีละประเภท
   พร้อมเทียบเอกสารกับเส้นทางเดิมอย่างน้อย 5 ใบต่อประเภท
4. บนเครื่องพัฒนาได้ตั้งรหัสผ่านบัญชี `superadmin@example.com` ใหม่เพื่อเข้าหน้าจอตรวจ
   และออกโทเคน API ชื่อ `dev-rehearsal` / `dev-emp` / `dev-appr` ไว้ — ควรลบทิ้งเมื่อไม่ใช้แล้ว
