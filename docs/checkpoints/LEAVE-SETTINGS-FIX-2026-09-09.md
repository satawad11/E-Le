## ช่องว่างของหน้าจอที่ปิดพร้อมกัน

- **ระยะขอบ/แบบอักษรมีผลจริง** — `LeaveDocumentTemplateResolver::pageStyle()` แนบ `@page` และ
  `@font-face` ต่อท้ายเอกสาร ลำดับ: ค่าของเวอร์ชันแม่แบบ (รายแบบฟอร์ม) มาก่อนค่ากลางของระบบ
  (หน้าตั้งค่าเป็นเซนติเมตร ส่วนเวอร์ชันแม่แบบเป็นมิลลิเมตร — แปลงให้ที่เดียว)
- **ตัวเลือกฟอนต์เหลือเฉพาะที่ติดตั้งไฟล์ไว้จริง** และมีเทสต์กันไม่ให้เพิ่มตัวเลือกที่ไม่มีไฟล์
- **หน้านโยบายมีช่องครบ** — เพดานต่อครั้ง อายุงานขั้นต่ำ เพดานสะสม ยอดสะสมรวม ชนิดหลักฐาน
- **สิทธิ์หน้ากับ API ตรงกัน** และหน้าประเภทการลาบอกเหตุผลเมื่อโหลดรายการแบบฟอร์มไม่ได้
- **ช่องเฉพาะแบบฟอร์มตรวจตามชนิด** (วันที่/ตัวเลข/ตัวเลือกตามรายการที่กำหนด)
- **การ์ดสรุปในหน้ารายงานใช้ตัวกรองเดียวกับตาราง** พร้อมบรรทัดบอกขอบเขตที่กำลังดู
- **audit ครบทุก CRUD ของการตั้งค่า** — ประเภทการลา ปีงบประมาณ นโยบายสิทธิ (ก่อน/หลัง)
