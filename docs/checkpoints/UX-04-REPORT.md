## 2. ผลการตรวจสอบและปรับปรุง 10 ด้านหลัก (10 Mobile UX Focus Areas)

| ลำดับ | หัวข้อการปรับปรุง | ผลการตรวจ | รายละเอียดการดำเนินการ |
|:---:|---|:---:|---|
| 1 | **Touch Target เหมาะสม (>= 44px)** | **PASS** | ปรับปุ่มไอคอน (กระดิ่งแจ้งเตือน, ปุ่มสลับรหัสผ่าน, ปุ่มอนุมัติ/ปฏิเสธ) ให้มีพื้นที่สัมผัสอย่างน้อย 44x44px ลดการกดพลาด |
| 2 | **ปุ่มสำคัญกดง่าย (Thumb-friendly CTAs)** | **PASS** | ปุ่ม Action สำคัญ (ส่งคำขอลา, อนุมัติ/ปฏิเสธ, เข้างาน/ออกงาน) ขยายเต็มจอหรือจัดวางในโซนที่นิ้วโป้งเอื้อมถึงง่าย |
| 3 | **ไม่มี Table บีบจนอ่านไม่ได้** | **PASS** | หน้ารายการใบลาและคำขออนุมัติใช้การจัดแสดงแบบการ์ด (Card View) พร้อม Data Table ที่เลื่อนได้นุ่มนวล |
| 4 | **ลดจำนวนขั้นตอนที่ไม่จำเป็น** | **PASS** | ปรับตัวเลือกระยะเวลาการลา (เต็มวัน/เช้า/บ่าย) เป็น Segmented Touch Chips แตะครั้งเดียวเลือกได้ทันที |
| 5 | **CTA หลักเห็นชัดเจน** | **PASS** | ปลดล็อกปุ่ม **"ยื่นใบลาใหม่"** และ **"ไปหน้าลงเวลา"** ให้แสดงเด่นชัดบนหน้าหลัก Dashboard บนมือถือ |
| 6 | **Sticky Action เหมาะสม** | **PASS** | ใช้ Header ติดหนึบเฉพาะระดับ AppShell โดยไม่บังพื้นที่กรอกฟอร์มหรือแป้นพิมพ์เสมือน |
| 7 | **Form กรอกบนมือถือสะดวก** | **PASS** | กำหนดขนาดฟอนต์ Input เป็น `1rem` (16px) ป้องกันปัญหา iOS Safari Auto-zoom หน้าจอเมื่อแตะฟอร์ม |
| 8 | **Modal ไม่ล้นจอ** | **PASS** | Modal ทุกตัวจำกัดความสูง `max-h-[90vh]` พร้อมเลื่อนภายในได้ และเว้นขอบหน้าจอ `p-4` ชัดเจน |
| 9 | **Keyboard ไม่บัง Input/Action** | **PASS** | Container มีระยะ Padding ด้านล่างเพียงพอ รองรับ Virtual Keyboard เลื่อนหน้าจอตาม Focus อัตโนมัติ |
| 10 | **Long Thai Text ไม่แตก** | **PASS** | ใช้ `break-words`, `truncate` และ `leading-relaxed` ในชื่อประเภทการลา เหตุผล และข้อความแจ้งเตือน |

## 3. สรุปผลการปรับปรุงรายหน้าจอหลัก (Mobile Journey Optimization)

### 3.1 หน้าหลัก (DashboardView.vue)
- แสดงปุ่ม CTA **"ยื่นใบลาใหม่"** ขนาดเต็มสัมผัส (`min-h-[44px]`) สำหรับผู้ใช้มือถือ
- ปรับ Card ลงเวลาวันนี้และปุ่ม **"ไปหน้าลงเวลา"** ให้จัดตำแหน่งสวยงามบนจอ 360-390px

### 3.2 เข้าสู่ระบบ (LoginView.vue)
- ขยายฟอนต์ Input เป็น `1rem` (16px) ขจัดปัญหา Auto-zoom บน iOS Safari
- ปรับปุ่มดูรหัสผ่าน (`eye-btn`) ให้มีขนาด `min-w-[44px] min-h-[44px]` แตะเปิด/ปิดได้ง่าย

### 3.3 การแจ้งเตือน (NotificationBell.vue)
- ขยายปุ่มกระดิ่งเป็นขนาด `44x44px`
- กำหนดความกว้าง Dropdown เป็น `w-[calc(100vw-2.5rem)] max-w-sm sm:w-80` ป้องกันป๊อปอัปหลุดขอบจอด้านขวา

### 3.4 ยื่นใบลา (LeaveRequestView.vue)
- เปลี่ยนปุ่มเลือกประเภทช่วงเวลาลา (เต็มวัน/เช้า/บ่าย) เป็น Segmented Card Chips แตะง่าย
- ปรับปุ่มส่งคำขอลาเป็น `w-full sm:w-auto min-h-[48px]` สัมผัสชัดเจน

### 3.5 รายการรออนุมัติ (ApprovalsView.vue)
- ปรับปุ่ม **"อนุมัติ"** และ **"ปฏิเสธ"** ในแต่ละการ์ดใบลาให้มีความสูง `min-h-[44px]` และขยายเต็มความกว้างแถวบนมือถือ

### 3.6 รายการใบลาของฉัน (MyLeavesView.vue)
- ปรับปุ่มดาวน์โหลดเอกสาร (PDF, Word) และปุ่มขอยกเลิกใบลาให้มี Touch Target ขั้นต่ำ 38-44px
- ข้อมูลสรุปวันและเหตุผลตัดบรรทัดกระชับ ไม่ดันการ์ดบิดเบี้ยว
