## รายละเอียดที่ควรรู้

- **`FieldDictionarySynchronizer` เป็นแหล่งความจริงเดียวของพจนานุกรม** — `DocumentEngineSeeder`,
  `GET /admin/document-engine/fields` และคำสั่ง `php artisan document:sync-fields` เรียกตัวเดียวกัน
  ทำงานซ้ำได้ ไม่ลบฟิลด์ใดทิ้ง (ปิดการใช้งานแทน) และ **ไม่เขียนทับป้ายชื่อ/กลุ่มที่ผู้ดูแลตั้งเอง**
  (มีเทสต์ยืนยันว่าซิงก์รอบถัดไปไม่กลืนการแก้ของผู้ดูแล)
- **ฟิลด์ที่เป็นก้อนข้อมูล (`stats`, `extra`) ถูกปิดในพจนานุกรมของแบบฟอร์ม PDF** เพราะวางเป็นช่องเดียว
  แล้วพิมพ์ไม่ได้ — แม่แบบ HTML อ่านจาก `LeaveDocumentFields::catalog()` คนละเส้นทาง จึงไม่กระทบ
- **สถิติอ้างด้วย id ของประเภทการลา ไม่ใช่ชื่อ** — เปลี่ยนชื่อประเภทภายหลังแล้วแบบฟอร์มไม่พัง
- **การเปิดใช้แยกสองชั้นตามเดิม** — `DOCUMENT_ENGINE_ENABLED` (`.env`) ปิดอยู่ = ทุกอย่างใช้เส้นทางเดิม
  ไม่ว่าจะตั้งค่าอะไรไว้ในฐานข้อมูล (มีเทสต์ยืนยัน)
