# เฟส 2 — กฎการลาตามระเบียบที่ยังขาด

> ต้องเปลี่ยน schema (เพิ่มคอลัมน์และตาราง ไม่ลบของเดิม) — ต้องได้รับอนุมัติข้อยกเว้น Production Freeze
> กฎทุกข้ออยู่ในนโยบายการลาที่มีรุ่น ไม่เขียนตัวเลขในโค้ด

## 2.1 สิ่งที่มีอยู่แล้วและใช้ต่อ

| กลไก | ที่อยู่ |
|---|---|
| โควตา, เพดานวันได้รับเงินเดือน, อายุราชการขั้นต่ำ, ยื่นล่วงหน้า, ย้อนหลัง, ครึ่งวัน, แนบหลักฐานเมื่อเกิน N วัน, สะสม | คอลัมน์ `leave_policies` |
| ครั้งเดียวในชีวิตราชการ, เพศ, ระยะห่างขั้นต่ำ, จำนวนครั้งต่อปี | `eligibility_rules` → `LeaveEligibilityRuleService` |
| สะสมลาพักผ่อน 20/30 วันตามอายุราชการ 10 ปี | `eligibility_rules.long_service_years` → `CarryForwardLeaves` |
| ยกเลิกบางส่วน | `LeaveAdjustment` |
| ยกเลิกทั้งใบพร้อมสายอนุมัติแยก | `LeaveCancellationController`, chain `cancellation` |

## 2.2 กฎใหม่ใน `eligibility_rules`

เพิ่มเป็นคีย์ JSON และ validator ใน `LeaveEligibilityRuleService` (คีย์ที่ไม่รู้จักให้ปฏิเสธตอนบันทึกนโยบาย เพื่อกันพิมพ์ผิดแล้วกฎไม่ทำงานเงียบ ๆ)

| คีย์ | ความหมาย | ใช้กับ | ตามคู่มือหัวข้อ |
|---|---|---|---|
| `first_service_year_paid_cap` | ปีงบประมาณแรกที่เริ่มรับราชการ ได้รับเงินเดือนไม่เกิน N วัน | ลากิจส่วนตัว = 15 | 4.1 |
| `paid_requires_service_months` | ได้รับเงินเดือนเฉพาะเมื่อรับราชการมาแล้ว N เดือน (ไม่ถึง = วันไม่ได้รับเงินเดือน ไม่ใช่ปฏิเสธ) | อุปสมบท/ฮัจญ์ = 12 | 6.6 |
| `ineligible_service_months` + `ineligible_cases` | ไม่มีสิทธิ์เมื่อรับราชการไม่ถึง N เดือน **เฉพาะกรณีที่ระบุ** | ลาพักผ่อน = 6 เดือน, 4 กรณี | 5.1 |
| `requires_event` | ต้องระบุวันที่ของเหตุ เช่น `child_birth`, `summons` | ลาช่วยภริยา, ตรวจเลือก/เตรียมพล | 3, 7 |
| `start_within_days_of_event` | ต้องเริ่มลาภายใน N วันนับจากวันของเหตุ | ลาช่วยภริยา = ตาม D-05 | 3 |
| `allow_split` | ลาเป็นช่วง ๆ ไม่ติดต่อกันได้จนครบสิทธิ์ (นับรวมทุกใบของเหตุเดียวกัน) | ลาช่วยภริยา | 3 |
| `requires_predecessor_type` | ต้องลาต่อเนื่องจากการลาประเภทที่ระบุ | ลาเลี้ยงดูบุตร ← ลาคลอด | 4.2 |
| `recallable` | ผู้บังคับบัญชาเรียกตัวกลับระหว่างลาได้ | ลากิจ, ลาพักผ่อน = true · ลาเลี้ยงดูบุตร = false | 4.1, 4.2, 5.4 |
| `career_total_cap_days` | เพดานรวมทุกใบตลอดอายุราชการ (รวมการต่อเวลา) | ติดตามคู่สมรส = 4 ปี, ศึกษาต่อ = 6 ปี | 8, 10 |
| `max_extensions` | ต่อเวลาได้กี่ครั้ง | ศึกษาต่อ = 2 | 8 |
| `report_back_within_days` | ต้องรายงานตัวกลับภายใน N วันหลังสิ้นสุด | อุปสมบท/ฮัจญ์ = 5, ตรวจเลือก/เตรียมพล = 7, องค์การระหว่างประเทศ = 15 | 6.4, 7.5, 9 |
| `must_begin_within_days` | ต้องเริ่มกิจกรรมจริงภายใน N วันนับจากวันเริ่มลา (ยืนยันตอนรายงานตัวกลับ) | อุปสมบท/ฮัจญ์ = 10 | 6.4 |
| `border_bonus_days` | วันเพิ่มสำหรับผู้ปฏิบัติงานประจำในจังหวัดชายแดนภาคใต้ต่อเนื่องไม่น้อยกว่า 3 เดือน | ลาพักผ่อน = 10 | 5.5 |
| `cancel_converts_to` | ยกเลิกหลังหยุดราชการไปแล้ว ให้นับวันที่หยุดไปแล้วเป็นการลาประเภทที่ระบุ | ลาคลอด, อุปสมบท/ฮัจญ์ → ลากิจส่วนตัว | 2.4, 6.5 |
| `supersedes_overlapping` | การลานี้ทำให้การลาอื่นที่คาบเกี่ยวสิ้นสุด และนับเป็นประเภทนี้ตั้งแต่วันเริ่ม | ลาคลอด | 2.5 |

## 2.3 ประเภทการลาใหม่

| ประเภท | สิทธิ์ | กฎหลัก |
|---|---|---|
| **ลากิจส่วนตัวเพื่อเลี้ยงดูบุตร** | ไม่เกิน 150 วันทำการ ไม่ได้รับเงินเดือน | `requires_predecessor_type` = ลาคลอด (ต้องเริ่มวันถัดจากวันสิ้นสุดลาคลอด) · `recallable` = false · ไม่หักจากโควตาลากิจ 45 วัน |

นับเป็นประเภทการลาแยกเพื่อให้รายงาน ทะเบียนคุม และเลขที่หนังสือ (`code_prefix`) แยกจากลากิจปกติ — ต้องให้งานบุคลากรยืนยันว่าแบบใบลาใช้ "แบบใบลาป่วย ลาคลอดบุตร ลากิจส่วนตัว" เดิมหรือไม่

### ความคืบหน้า 2.3 (18/10/2569) — ทำแล้วโดยไม่เปลี่ยน schema
- migration `2026_10_19_150000_create_childcare_leave_type.php` สร้างประเภทการลา "ลากิจส่วนตัวเพื่อเลี้ยงดูบุตร" (ใช้แบบใบลาและอักษรนำ ลก. เดียวกับลากิจส่วนตัว) พร้อมนโยบายของทุกประเภทบุคลากร: **โควตา 0 วันจนกว่าเจ้าของระบบจะกรอก**, ไม่ได้รับเงินเดือน, นับวันทำการ, เพศหญิง
- กฎ `requires_predecessor_leave_type_id` ใน `LeaveEligibilityRuleService`: ต้องมีลาคลอดบุตรที่ **อนุญาตแล้ว** และเริ่มหลังวันสุดท้ายของลาคลอด โดยระหว่างกลางมีได้เฉพาะวันหยุด (ตาม `TimeService::isWorkingDay`)
- ยังไม่ทำ: การห้ามเรียกตัวกลับระหว่างลา (ระบบยังไม่มีการเรียกตัวกลับ)

## 2.4 รูปแบบการยื่น: "ขออนุญาต" กับ "รายงานลา"

เพิ่ม `leave_types.request_mode`:
- `approval` (ค่าเริ่มต้น) — ต้องได้รับอนุญาตก่อนหยุดราชการ เว้นลาป่วย/ลาคลอดที่ยื่นย้อนหลังได้ตามนโยบาย
- `notification` — **ลาเข้ารับการตรวจเลือกหรือเข้ารับการเตรียมพล**: รายงานลาภายใน 48 ชั่วโมงนับจากรับหมายเรียก แล้วไปได้โดยไม่ต้องรอคำสั่ง (คู่มือหัวข้อ 7) ระบบสร้างใบลาสถานะ "รายงานแล้ว" และส่งให้ผู้บังคับบัญชา "รับทราบ" ตามลำดับ ไม่มีปุ่ม "ไม่อนุญาต"

## 2.5 ข้อมูลที่ต้องเพิ่มในใบลา

| คอลัมน์ / ตาราง | ใช้ทำอะไร |
|---|---|
| `leaves.event_date`, `leaves.event_type` | วันคลอดของภริยา วันรับหมายเรียก — ใช้ตรวจ `start_within_days_of_event` และรวมสิทธิ์ของเหตุเดียวกัน |
| `leaves.parent_leave_id` | ใบลาต่อเนื่อง (ลาเลี้ยงดูบุตรต่อจากลาคลอด) และการต่อเวลา (ศึกษาต่อ ติดตามคู่สมรส) |
| `leaves.converted_from_leave_id` | ใบลาที่เกิดจากการแปลงประเภท (ยกเลิกลาคลอด → ลากิจ) |
| ตาราง `leave_report_backs` | การรายงานตัวกลับ: วันที่กำหนด วันที่รายงานจริง วันที่เริ่มกิจกรรมจริง หลักฐาน ผู้รับรายงาน |
| ตาราง `leave_recalls` | การเรียกตัวกลับ: ผู้สั่ง วันที่กลับ เหตุผล — ระบบสร้าง `LeaveAdjustment` คืนวันที่ยังไม่ได้ใช้ และถือว่าการลาสิ้นสุดก่อนวันเดินทางกลับ |
| `leave_approvals.evidence_requested` | ผู้อนุมัติสั่งให้แนบใบรับรองแพทย์แม้ลาไม่ถึงเกณฑ์ (D-06) ใบลาค้างที่ขั้นนั้นจนกว่าจะแนบ |

## 2.6 พฤติกรรมเฉพาะประเภท

**ลาป่วย**
- ยื่นในวันแรกที่กลับมาปฏิบัติราชการได้ และให้ผู้อื่นยื่นแทนได้เมื่อลงชื่อเองไม่ได้ (มีการบันทึกการลาแทนแล้ว)
- เกินเพดานวันได้รับเงินเดือน (`max_days_with_pay`) ให้ระบบ **เลือกสายอนุมัติระดับสูงขึ้น** ตามตารางอำนาจในเฟส 3 แทนการแยกเป็นวันไม่ได้รับเงินเดือนเฉย ๆ

**ลาคลอดบุตร**
- นับวันหยุดราชการด้วย (`exclude_holidays` = false — มีแล้ว)
- ยื่นแล้วคาบเกี่ยวใบลาอื่นที่อนุมัติแล้ว: ระบบตัดใบลาเดิมให้สิ้นสุดก่อนวันเริ่มลาคลอด คืนวันลาที่ตัดผ่าน ledger และแจ้งเจ้าของใบลากับงานบุคลากร
- ขอยกเลิกหลังเริ่มหยุดราชการแล้ว: วันที่หยุดไปแล้วแปลงเป็นลากิจส่วนตัว (`cancel_converts_to`)

**ลากิจส่วนตัว**
- ปีงบประมาณแรกได้รับเงินเดือน 15 วัน ส่วนที่เกินเป็นวันไม่ได้รับเงินเดือน — ต้องมีวันเริ่มรับราชการที่ถูกต้อง (เฟส 4)
- ต้องได้รับอนุญาตก่อนหยุด เว้นแต่มีเหตุจำเป็น — เพิ่มช่อง "เหตุจำเป็นที่ยื่นก่อนไม่ได้" เมื่อยื่นย้อนหลัง

**ลาพักผ่อน**
- สิทธิ์ 10 วันต่อปีงบประมาณ **ไม่คิดตามสัดส่วน** เลิกใช้ `leave_types.is_prorated` กับประเภทนี้
- ไม่มีสิทธิ์ในปีที่รับราชการไม่ถึง 6 เดือน **เฉพาะ 4 กรณี** ในคู่มือหัวข้อ 5.1 ไม่ใช่ทุกคน — ต้องรู้ "เหตุของการบรรจุ" (เฟส 4)

**ลาอุปสมบท / ฮัจญ์**
- ใช้ได้ครั้งเดียว (มีแล้ว) ยื่นล่วงหน้า 60 วัน (เฟส 1) ได้รับเงินเดือนเมื่อรับราชการ 12 เดือน
- หลังสิ้นสุด ต้องรายงานตัวกลับภายใน 5 วัน และยืนยันวันอุปสมบท/วันออกเดินทางจริง (ต้องไม่เกิน 10 วันจากวันเริ่มลา) ระบบแจ้งเตือนเจ้าตัวและงานบุคลากรเมื่อเลยกำหนด

**ลาศึกษา ฝึกอบรม ปฏิบัติการวิจัย ดูงาน / ลาไปปฏิบัติงานในองค์การระหว่างประเทศ / ลาติดตามคู่สมรส / ลาไปฟื้นฟูสมรรถภาพด้านอาชีพ**
- เป็นการลายาวที่ส่วนใหญ่เกินอำนาจวิทยาลัย ระบบทำหน้าที่ **ตรวจคุณสมบัติเบื้องต้น เก็บเอกสาร ส่งต่อ และบันทึกผล** (เฟส 3 ขั้น "ส่งต่อผู้มีอำนาจภายนอก")
- รายการตรวจคุณสมบัติเป็น checklist ในนโยบาย (เช่น พ้นทดลองปฏิบัติหน้าที่ราชการ, รับราชการไม่น้อยกว่า 1 ปี, ทำสัญญาชดใช้) ให้เจ้าหน้าที่ติ๊กพร้อมแนบหลักฐาน — ระบบไม่ตัดสินแทน
- รองรับการต่อเวลาเป็นใบลาลูก (`parent_leave_id`) และตรวจ `career_total_cap_days`, `max_extensions`
- เพิ่มช่อง "บันทึกลงทะเบียนประวัติ (ก.พ.7) แล้ว" พร้อมผู้บันทึกและวันที่

## 2.7 การนับวัน

แยกฟังก์ชันนับวันเป็นบริการเดียว `LeaveDayCounter` ที่ใช้ทั้งตอนยื่น อนุมัติ ยกเลิก และรายงาน:
- วันทำการ: ไม่นับวันหยุดราชการและวันหยุดของหน่วยงาน (`WorkCalendarException`)
- วันปฏิทิน: ลาคลอด อุปสมบท/ฮัจญ์ และการลายาว
- ครึ่งวัน: ตาม `allow_half_day`
- ใบลาเก็บ **ผลการนับ ณ วันยื่น** และนับใหม่เมื่อมีการประกาศวันหยุดเพิ่ม โดยแสดงความต่างให้งานบุคลากรยืนยัน ไม่แก้เงียบ ๆ

## 2.8 Automated tests ที่ต้องมี

ทุกคีย์ในหัวข้อ 2.2 ต้องมี test กรณีผ่านและกรณีถูกปฏิเสธ (หรือแบ่งวันได้รับ/ไม่ได้รับเงินเดือนถูกต้อง) และ test เหล่านี้:
- ลาเลี้ยงดูบุตรยื่นได้เฉพาะต่อจากลาคลอด และเรียกตัวกลับไม่ได้
- ลาคลอดคาบเกี่ยวลาพักผ่อนที่อนุมัติแล้ว → ลาพักผ่อนถูกตัด วันคืนเข้าโควตา ledger ตรงกับยอด
- ยกเลิกลาคลอดหลังเริ่มหยุด → เกิดใบลากิจตามวันที่หยุดจริง
- รายงานลาตรวจเลือก: ไม่มีขั้น "ไม่อนุญาต" และแจ้งผู้บังคับบัญชาครบลำดับ
- ลาช่วยภริยาแบ่ง 3 ช่วง รวมเกิน 15 วันทำการถูกปฏิเสธ / ช่วงที่เริ่มเกินกำหนดนับจากวันคลอดถูกปฏิเสธ
- การเรียกตัวกลับคืนวันลาที่ยังไม่ได้ใช้ และผู้ไม่มีอำนาจสั่งเรียกตัวกลับไม่ได้ (authorization)
