# ACCEPTANCE CRITERIA (REBUILD-2569)

ระบบพร้อมเปิดใช้ (จบ R-09) เมื่อ:

1. ผู้ใช้ตัวอย่างทุก persona ในแผน §8.3 เห็นเมนูและข้อมูลตรงตาราง (เทสต์อัตโนมัติ + UAT)
2. คนเดียวหลายตำแหน่ง (ครู + หัวหน้าแผนก + รองฯ ต่างฝ่าย) ได้สิทธิ์ถูกต้องและไม่รั่วข้ามฝ่าย
3. dry-run สายอนุมัติ: บุคลากรทุกคน × ทุกประเภทการลา หาผู้อนุมัติได้ครบ ถูกฝ่าย ไม่มีกรณี fallback
4. ไม่มีใครอนุมัติหรือแก้ข้อมูลควบคุมของตนเองได้ รวมถึงผู้ดูแลระบบ
5. ข้อมูลอ่อนไหวถูกเข้ารหัส ปิดบังตามสิทธิ์ และทุกการเปิดดูมี log พร้อมเหตุผล
6. บัญชีของบุคลากรที่พ้นสภาพใช้งานไม่ได้ภายใน 24 ชั่วโมงหลังบันทึก
7. MFA บังคับครบทุกกลุ่มที่กำหนด
8. ผู้ดูแลเพิ่มสิทธิ์ให้โมดูลผ่านหน้าจอได้โดยไม่แก้โค้ด และสิทธิ์เสี่ยงสูงต้องผ่านคนที่สอง
9. ทดสอบเจาะระบบไม่พบปัญหา critical/high
