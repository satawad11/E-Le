## 🏛️ 1. ภาพรวมสถาปัตยกรรมสถานศึกษาอาชีวศึกษา

ระบบ E-la ได้รับการออกแบบโครงสร้างรองรับการบริหารจัดการสถานศึกษาอาชีวศึกษาอย่างสมบูรณ์แบบ:

```
[ โครงสร้างการบริหาร ๔ ฝ่ายหลัก สอศ. ]
├── 1. ฝ่ายบริหารทรัพยากร (งานบุคลากร, งานการเงิน, งานพัสดุ, งานบริหารทั่วไป ฯลฯ)
├── 2. ฝ่ายแผนงานและความร่วมมือ (งานแผนงานและงบประมาณ, งานศูนย์ข้อมูลสารสนเทศ, งานความร่วมมือ ฯลฯ)
├── 3. ฝ่ายพัฒนากิจการนักเรียนนักศึกษา (งานกิจกรรมฯ, งานครูที่ปรึกษา, งานปกครอง ฯลฯ)
└── 4. ฝ่ายวิชาการ (แผนกวิชาช่างยนต์, แผนกวิชาช่างไฟฟ้า, งานพัฒนาหลักสูตรฯ, งานวิทยบริการ ฯลฯ)
```

### บุคลากร ๕ กลุ่มตามระเบียบราชการ:
1. **ข้าราชการครูและบุคลากรทางการศึกษา** (เกณฑ์วันลาสะสมไม่เกิน ๒๓ วันทำการ/รอบการประเมิน)
2. **พนักงานราชการ** (เกณฑ์วันลาไม่เกิน ๑๓ วันทำการ/รอบ)
3. **ครูอัตราจ้าง / ลูกจ้างชั่วคราว**
4. **ลูกจ้างประจำ**
5. **เจ้าหน้าที่และบุคลากรสายสนับสนุน**

## ⚙️ 2. ขั้นตอนการย้ายและตั้งค่าข้อมูลเริ่มต้น

### 2.1 การนำเข้าผัง ๔ ฝ่าย สอศ. สู่ฐานข้อมูล
สำหรับระบบที่ติดตั้งใหม่หรือระบบเดิมที่ต้องการปรับเข้าสู่โครงสร้าง ๔ ฝ่าย ให้รันคำสั่ง:

```bash
docker exec eleave_backend php artisan db:seed --class=VocationalOrgStructureSeeder
```
*คำสั่งนี้ทำงานแบบ Non-Destructive และ Idempotent (รันซ้ำได้ปลอดภัย ไม่ทับชื่อหรือความสัมพันธ์ที่แอดมินแก้ไขแล้ว)*

### 2.2 การแต่งตั้งผู้ดำรงตำแหน่งบริหารและผู้รักษาการแทน
1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ (Admin)
2. ไปที่เมนู **ตั้งค่าระบบ** $\rightarrow$ **ผู้จัดการหน่วยงาน** (`/admin/org-unit-managers`)
3. แต่งตั้งผู้บริหารตามลำดับ:
   - **ผู้อำนวยการวิทยาลัย** (ระดับสถานศึกษา)
   - **รองผู้อำนวยการ ๔ ฝ่าย** (บริหารทรัพยากร, แผนงานฯ, พัฒนากิจการฯ, วิชาการ)
   - **หัวหน้างาน / หัวหน้าแผนกวิชา**
4. กำหนดวันเริ่มต้นปฏิบัติหน้าที่ (`effective_from`) ให้มีผลตั้งแต่วันเริ่มต้นปีงบประมาณ

### 2.3 การกำหนดประเภทบุคลากรและสังกัดหน่วยงาน
1. ไปที่เมนู **ผู้ใช้งาน** $\rightarrow$ **กำหนดประเภทบุคลากร** (`/admin/personnel-assignments`)
2. ตรวจสอบให้บุคลากรทุกคนได้รับการผูกประเภท (เช่น ข้าราชการครู, พนักงานราชการ) และสังกัดหน่วยงานย่อยภายใต้ ๔ ฝ่ายหลัก

## 📟 3. คู่มือการใช้งานศูนย์นำเข้าไฟล์สแกนเวลา (Smart Biometric Hub)

ระบบรองรับการนำเข้าข้อมูลเวลาปฏิบัติราชการจากเครื่องสแกนลายนิ้วมือและใบหน้า (ZKTeco, HIP, Hikvision) เข้าสู่ระบบอย่างสะดวก:

```
[ กระบวนการนำเข้าไฟล์บันทึกเวลา ]
1. ลากวางไฟล์ (.dat/.txt/.csv/.xlsx) 
   └──> 2. Auto-Detect รูปแบบไฟล์ & แปลงเวลา Timezone
        └──> 3. จับคู่ Enroll ID กับรหัสบุคลากร (Identity Map)
             └──> 4. Reconciliation Engine: ตัดสแกนซ้ำ + บันทึกเวลาเข้า-ออก
```

### ขั้นตอนการนำเข้าไฟล์:
1. ไปที่เมนู **การลงเวลา** $\rightarrow$ **สรุปเวลาปฏิบัติงาน** $\rightarrow$ คลิกปุ่ม **"นำเข้าไฟล์สแกน (Biometric Hub)"** หรือเข้าผ่าน URL `/admin/attendance/biometric-hub`
2. **ลากไฟล์มาวาง** ในกรอบ Drag & Drop (รองรับไฟล์ `.dat`, `.txt`, `.csv`, `.xlsx`)
3. เลือก **เขตเวลา (Timezone)** เช่น `Asia/Bangkok (UTC+7)`
4. คลิกปุ่ม **"เริ่มนำเข้าและประมวลผลข้อมูล"**
5. ระบบจะแสดงแถบความคืบหน้า และรายงานผลสรุป:
   - จำนวนเหตุการณ์บันทึกเวลาทั้งหมด (`total_events`)
   - จำนวนรายการที่นำเข้าและจับคู่สำเร็จ (`imported`)
   - จำนวนรายการที่ข้ามเนื่องจากข้อมูลซ้ำซ้อน (`skipped`)

## 📊 4. คู่มือการใช้งานระบบรายงานประเมิน ก.ค.ศ. และแฟ้มหลักฐาน ว PA

ระบบ E-la ช่วยให้งานบุคลากรและครูจัดเตรียมเอกสารประเมินการเลื่อนขั้นเงินเดือนและ ว PA ได้ในคลิกเดียว:

### 4.1 การดูรายงานสรุปการประเมินวันลา ก.ค.ศ.
1. ไปที่เมนู **รายงาน** $\rightarrow$ **รายงานการลาราชการ** $\rightarrow$ คลิกปุ่ม **"รายงานประเมิน ก.ค.ศ. (ว PA)"** หรือเข้าผ่าน URL `/reports/vocational-evaluation`
2. เลือกรอบการประเมิน ก.ค.ศ. สำเร็จรูป:
   - `[ รอบที่ ๑: ๑ ต.ค. – ๓๑ มี.ค. ]`
   - `[ รอบที่ ๒: ๑ เม.ย. – ๓๐ ก.ย. ]`
   - `[ ปีงบประมาณ: ๑ ต.ค. – ๓๐ ก.ย. ]`
3. กรองตามฝ่ายบริหาร (๔ ฝ่าย) หรือประเภทบุคลากร
4. ระบบจะสรุปจำนวนวันลาแต่ละประเภท วันมาสาย ขาดงาน พร้อมแสดง **ป้ายเตือนสีแดง** สำหรับผู้ที่ลาเกินเกณฑ์ ๒๓ วันทำการ (หรือเกิน ๑๓ วันสำหรับลูกจ้าง)

### 4.2 การเปิดดูแฟ้มหลักฐาน ว PA รายบุคคล (Teacher PA Evidence Pack)
1. ในตารางรายงาน คลิกปุ่ม **"ดูแฟ้มหลักฐาน (ว PA)"** ที่แถวของบุคลากรท่านนั้น
2. โมดอลจะแสดงชุดข้อมูลหลักฐานครบถ้วน:
   - สรุปวันลาป่วย ลากิจ ลาพักผ่อน วันมาสาย ขาดงาน
   - รายการประวัติใบลาทั้งหมดที่ได้รับการอนุมัติในรอบประเมิน พร้อมเลขอ้างอิงและวันที่
   - สามารถพิมพ์หรือคัดลอกข้อมูลไปแนบในระบบ DPA (Digital Performance Appraisal) ของ ก.ค.ศ. ได้ทันที

## 🛡️ 5. คู่มือความปลอดภัย การสำรอง และการซ้อมกู้คืนข้อมูล

### 5.1 การสั่งสำรองข้อมูลระบบ (Manual Backup)
- **บน Windows Server (PowerShell):**
  ```powershell
  powershell -ExecutionPolicy Bypass -File docker/scripts/backup.ps1
  ```
- **บน Linux / Docker Host (Bash):**
  ```bash
  bash docker/scripts/backup.sh
  ```
*ไฟล์สำรองจะถูกบีบอัดเป็น `.zip` ประกอบด้วยฐานข้อมูล SQL และไฟล์เอกสารที่ปลอดภัย (`storage/app/private`)*

### 5.2 การซ้อมกู้คืนข้อมูล (Restore Drill)
- **บน Windows Server (PowerShell):**
  ```powershell
  powershell -ExecutionPolicy Bypass -File docker/scripts/restore.ps1 -BackupFile "C:\path\to\backup.zip"
  ```
- **บน Linux (Bash):**
  ```bash
  bash docker/scripts/restore.sh /path/to/backup.zip
  ```
