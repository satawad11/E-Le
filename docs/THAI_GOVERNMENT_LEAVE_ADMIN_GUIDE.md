# คู่มือผู้ดูแลระบบลางานภาครัฐ

## การตั้งค่าที่ต้องทำก่อนเปิดใช้งาน

1. กำหนด `personnel_type` ให้ผู้ใช้ทุกคน
2. ตรวจนโยบายแต่ละประเภทบุคลากรและวันที่มีผลที่หน้า `/admin/leave-policies`
3. ตรวจปีงบประมาณ วันหยุดราชการ และวันทำงานชดเชย
4. กำหนด permission `leave.management.manage`, `leave.approval.hr`, `leave.report.view`, `manage_leave_types`
5. ตรวจลำดับผู้อนุมัติและผู้ได้รับมอบอำนาจ
6. ตั้งค่า `leave_evidence_retention_days` ตามระเบียบสารบรรณ/นโยบายคุ้มครองข้อมูลของหน่วยงาน

ค่า policy ที่ seed ให้เป็นค่าเริ่มต้นสำหรับนำไปตรวจทาน ไม่ใช่คำวินิจฉัยทางกฎหมาย หน่วยงานต้องตรวจประเภทบุคลากร ข้อบังคับเฉพาะ และคำสั่งมอบอำนาจก่อนใช้งานจริง

## งานประจำวัน

- `php artisan leave:governance` แจ้งใบค้างอนุมัติและวันลาใกล้เริ่ม
- `php artisan leave:governance --purge` ลบหลักฐานของใบที่พ้น retention แล้ว
- สำรองฐานข้อมูลและ `storage/app/private/leave-evidences` เป็นชุดเดียวกัน

## หลักความปลอดภัย

- ห้ามเผยแพร่ `storage/app/private` ผ่าน web server
- การดาวน์โหลดหลักฐานต้องผ่าน authenticated API เท่านั้น
- ห้ามลบใบลาที่อนุมัติแล้ว ให้ใช้ void หรือคำขอยกเลิก
- ตรวจ `leave_audit_logs` เมื่อมีข้อพิพาทหรือการแก้ไขข้อมูล
