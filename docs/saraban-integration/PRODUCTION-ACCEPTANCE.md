## ฉ. สิ่งที่ยังไม่มีในระบบ — ต้องรู้ก่อนตัดสินใจขึ้นระบบ

รายการนี้ **ไม่ใช่ข้อบกพร่อง** แต่เป็นขอบเขตที่ยังไม่ได้ทำ · ผู้ตัดสินใจต้องรู้ว่า
กำลังรับอะไรไป

| เรื่อง | สถานะปัจจุบัน | ผลต่อผู้ใช้ | รหัส |
|---|---|---|---|
| หน้าจอเลือกพื้นที่ปกปิดข้อมูล | มี API ครบ ไม่มีหน้าจอ | ต้องส่งพิกัดผ่าน API | RISK-48 |
| หน้าจอมุมมองที่บันทึกไว้ / เปรียบเทียบเวอร์ชัน | มี API ครบ ไม่มีหน้าจอ | ใช้ผ่าน API เท่านั้น | RISK-47 |
| หน้าจออายัดและคิวทำลายเอกสาร | มี API ครบ ไม่มีหน้าจอ | ใช้ผ่าน API เท่านั้น | RISK-51 |
| หน้าจอจัดการเวอร์ชันสายงานเดินหนังสือ | ไม่มี | แก้สายงานต้องผ่านผู้พัฒนา | RISK-26 |
| การมอบอำนาจรับทราบแทน | ไม่มี | ผู้รักษาการรับทราบแทนไม่ได้ | RISK-35 |
| MFA สำหรับการยืนยันตัวตนซ้ำ | ใช้รหัสผ่านอย่างเดียว | ยังไม่มี MFA ทั้งระบบ | RISK-29 |
| ลากวางตำแหน่งลายเซ็น | กรอกเป็นตัวเลข | ผู้ลงนามต้องระบุพิกัด | RISK-30 |
