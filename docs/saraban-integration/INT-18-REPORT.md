### 1. ตัวตนของหนังสือห้ามเปลี่ยน — บังคับที่ระดับ schema

การจัดกลุ่ม การปกปิด และการบันทึกมุมมอง เป็นสิ่งที่เกิด **รอบ ๆ** หนังสือ
ไม่ใช่ **กับ** หนังสือ · migration ของเช็คพอยต์นี้จึง **ไม่เพิ่มคอลัมน์ใดลง
`saraban_documents` แม้แต่คอลัมน์เดียว** — ข้อบังคับนี้ตรวจได้จากตัว migration เอง
ไม่ต้องเชื่อคำอธิบาย

เทสต์ `grouping a document into a case never changes the document` เก็บค่าทะเบียน
ก่อนและหลังแล้วเทียบตรง ๆ

### 2. สารบบเรื่องต้องไม่กลายเป็นช่องค้นพบหนังสือ

สารบบเรื่องหนึ่งมีหนังสือจากหลายหน่วยงาน · ถ้าแสดงทุกฉบับให้ทุกคนที่เปิดสารบบ
มันจะกลายเป็นทางลัดที่ข้ามขอบเขตหน่วยงานไปทั้งหมด

หน้ารายละเอียดจึงกรองด้วย `DocumentPolicy` รายฉบับ และ **บอกจำนวนที่ถูกซ่อน**
เพื่อไม่ให้ผู้ใช้เข้าใจผิดว่าสารบบมีแค่นี้ · การเพิ่มหนังสือเข้าสารบบก็ต้องเห็น
หนังสือฉบับนั้นได้ก่อนเช่นกัน

### 3. การปกปิดข้อมูล — กล่องดำอย่างเดียวไม่ใช่การปกปิด

> **นี่คือความผิดพลาดที่หน่วยงานราชการทั่วโลกเคยทำจนข้อมูลลับหลุด**

การวาดกล่องทึบทับข้อความใน PDF **ไม่ได้ลบอะไรเลย** — ข้อความยังอยู่ใต้กล่อง
และคัดลอกออกมาได้ด้วยการลากเลือกใน PDF reader ธรรมดา หรือคำสั่ง `strings` บรรทัดเดียว

FPDI ที่โครงการใช้อยู่ **นำเข้าหน้าเดิมมาทั้งแผ่นแบบไม่แก้ content stream** จึงไม่มี
ทางลบชั้นข้อความได้ด้วยตัวเอง · บริการนี้จึงทำสองขั้นเสมอ:

1. วาดกล่องทึบด้วย FPDI ตามพิกัดที่เลือก (PDF point จากมุมซ้ายบน — ระบบเดียวกับ INT-10)
2. **แปลงทั้งแผ่นเป็นภาพด้วย Ghostscript `pdfimage24`** ซึ่งทำลายชั้นข้อความ
   ทั้งไฟล์อย่างถาวร รวมถึงข้อความที่อยู่ใต้กล่อง

**ถ้าขั้นที่ 2 ทำไม่ได้ จะไม่สร้างสำเนาเลย** — สำเนาที่ปกปิดไม่จริงอันตรายกว่า
การไม่มีสำเนา เพราะผู้ใช้จะเชื่อว่ามันปลอดภัยแล้วส่งออกไป

**ราคาที่ต้องจ่าย:** สำเนาที่ปกปิดเลือกข้อความไม่ได้อีก (เป็นภาพ) และไฟล์ใหญ่ขึ้น
— เป็นพฤติกรรมที่ถูกต้องสำหรับสำเนาที่ปล่อยออกนอกระบบ

**ต้นฉบับไม่ถูกแตะเลย** — ไม่เพิ่มเวอร์ชัน ไม่เปลี่ยน hash และยังเปิดได้โดย
ผู้มีสิทธิ์เสมอ · ถ้าปกปิดทับต้นฉบับ ระบบจะทำลายหลักฐานที่ตัวเองมีหน้าที่เก็บ

### 4. การเปรียบเทียบ — สิ่งที่ **ไม่** ทำ สำคัญพอ ๆ กับสิ่งที่ทำ

รายงาน: ค่าในทะเบียนที่ต่างกัน · file hash · จำนวนหน้า · ขนาดไฟล์

**ไม่เทียบเนื้อความในไฟล์โดยตั้งใจ** — การอ่านข้อความออกจาก PDF ต้องพึ่งตัวแยก
ข้อความที่ให้ผลต่างกันตามฟอนต์และวิธีสร้างไฟล์ (ไฟล์ไทยที่ฝังฟอนต์แบบ subset
มักอ่านออกมาเป็นอักขระที่ไม่ใช่ภาษาไทยเลย) · **ความต่างที่รายงานผิดในเอกสารราชการ
อันตรายกว่าการไม่รายงาน เพราะคนจะเชื่อมัน**

จำนวนหน้าคืน `null` เมื่ออ่านไม่ได้ ไม่ใช่ `0` — หน้าจอต้องแยกได้ระหว่าง
"เท่ากัน" กับ "ไม่รู้"

### 5. มุมมองที่บันทึกไว้ — เก็บคำถาม ไม่เก็บคำตอบ

เก็บ **เงื่อนไขการค้น** ไม่ใช่ผลลัพธ์ · ผลลัพธ์ที่แช่ไว้จะล้าสมัยทันทีที่มีหนังสือ
ใหม่เข้ามา และกลายเป็นข้อมูลที่หลอกผู้ใช้ว่างานเสร็จแล้ว

**มุมมองที่แบ่งปันไม่ได้แบ่งปันข้อมูล** — คนอื่นเปิดมุมมองเดียวกันจะเห็นเฉพาะ
หนังสือที่ตนมีสิทธิ์เห็นอยู่แล้ว เพราะตัวกรองถูกนำไปใช้กับ query ที่ผ่าน
`DocumentPolicy` ตามปกติ · และ **แก้ได้เฉพาะเจ้าของ** แม้จะแบ่งปันแล้ว
