# UI/UX STANDARDS
- ผู้ใช้เห็นภาษาไทย 100%
- Responsive Mobile/Tablet/Desktop
- Consistent navigation, breadcrumb, search, filter
- Loading/empty/error/success states
- Accessible labels, keyboard support, readable contrast, adequate touch targets
- Confirm destructive/high-impact actions
- Approval screens show requester, reason, history, attachments and policy context clearly
- Never expose raw technical errors to end users
